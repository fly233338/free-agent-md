# 项目协作约定

- 只有用户明确要求编译时才运行编译、Gradle 测试或构建；不得擅自编译。
- 诚实区分已经实现、已经检查和尚未验证的内容。进度及下一步应说明可继续做的功能，不以编译或真机验证作为下一步建议。
- 更新日志只记录功能、改进和修复，不加入“本次本地仅完成源码与 Git 差异检查，未编译、运行 Gradle 测试或测量性能”等验证状态说明；验证进度在聊天回复中如实说明。
- 设置图标必须准确对应功能语义，不得为填补图标库缺项而借用无关角色；同页不同功能不得直接复制同一图标参数。优先使用同一套原生线性矢量，无合适字形时按统一 24dp 网格、线宽和光学边距自绘，通过现有 tint 适配主题。提交前检查实际字形与相邻条目，不能只凭资源名判断是否重复；详细要求见 [设置语义图标约定](artwork/settings-icons/README.md)。
- 设置层级命名应描述当前范围，子入口和子页不得与父分类同名造成“设置里还有同名设置”；入口、页标题与搜索目录共用命名来源。可增长的选项列表使用菜单或按需打开的编辑器，不在主设置页重复铺开；已有直接数值输入时，不叠放功能重复的滑块。保留当前值、预设选择、范围校验与原有保存逻辑。
- 所有 UI 调整都必须同时考虑液态玻璃开启和关闭后的 MD3、Miuix 路径，不能只处理其中一种材质。共同存在的布局问题应分别修复两条路径，并检查手机、大屏与窄分屏；仅材质专属的变化仍需显式隔离，不得借用玻璃参数改变原生样式。
- 异步计数和标签必须区分“未知”与真实为 0，并绑定当前内容身份；首帧优先使用当前内容已有的详情或缓存数据，避免延后加载的默认值覆盖。带异步数量的 dock 应显式提供测量依据（详情种子、格式上限或占位），将文字更新与几何测量分离；不得只用宽度动画掩盖数据到达导致的尺寸跳变。玻璃与原生两条路径都要检查内容切换、真实零值、加载失败和长计数。
- 液态玻璃开启后的专属布局、尺寸、间距、字体和动画改动，必须由液态玻璃开关显式隔离，不得改变关闭后的 MD3、Miuix 原生组件。修改共用参数、页面调用参数或默认值时，检查开启与关闭两条调用链；需要差异时使用材质分支，保留原生参数和默认行为，并在共享入口注释说明边界。不得用全局缩小槽位、移动文字或改原生默认值来补偿液态玻璃的视觉问题。
- 涉及蓝雪女仆品牌图片、Lottie、状态反馈时，先阅读 [品牌动效制作约定](artwork/brand-motion/AGENTS.md)，保留用户已确认的角色身份和各状态的表情、姿态区别。
- 液态玻璃标签栏使用等宽槽位时，选中指示器应与完整槽位对齐，避免短标签在 dock 固有内边距之外再多一层留白。页面入口应显式选择玻璃专属参数，不改变共享默认值及关闭后的原生调用参数；确需随文字或计数变化调整指示器宽度的入口保留显式策略。检查首项、末项、长短标签及横向滚动后的对齐关系。
